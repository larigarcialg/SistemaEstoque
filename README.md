
# 📦 Sistema de Estoque em Java

## 📖 Sobre o projeto

Este projeto foi desenvolvido em Java com o objetivo de praticar os conceitos de Programação Orientada a Objetos (POO), manipulação de coleções com `ArrayList` e implementação de operações CRUD.

O sistema permite gerenciar um estoque de produtos por meio de um menu interativo no console.

---

## 🚀 Funcionalidades

- ✅ Cadastrar produtos
- ✅ Listar produtos
- ✅ Buscar produto por código
- ✅ Atualizar quantidade em estoque
- ✅ Remover produto
- ✅ Impedir cadastro de produtos com código duplicado
- ✅ Validar preço e quantidade

## ▶️ Como executar

1. Clone este repositório.
2. Abra o projeto no Eclipse.
3. Execute a classe `Main.java`.
4. Utilize o menu para gerenciar o estoque.
